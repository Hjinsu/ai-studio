## 1. 목적 및 변경 범위

AI Studio는 한 명의 운영자가 개인 PC에서 독창적이고 시청 가치가 높은 YouTube 콘텐츠를 합리적인 비용으로 자동 제작하여 지속적인 수익을 추구하는 프로그램이다. 제작량이나 자동화율만으로 성공을 판단하지 않는다. 영상 제작 자동화와 창작 품질을 함께 달성하며, 수익화 승인과 수익은 보장하지 않는다.

이번 변경은 V2-00 재수행이나 V2-01의 대규모 재설계가 아니다. 기존 V1~V6, v2 기준선, 비용 보호·복구·중복 방지·게시 승인 및 C/D 보존 정책을 유지한다. 품질 요구사항은 V2-02~06에서 해당 제품 기능을 구현할 때 반영한다. 기업용 품질 관리 플랫폼이나 별도 다중 에이전트 인프라는 만들지 않는다.

## 2. 핵심 원칙

1. 자동화: 채널 설정과 제작 시작 후 소재 입력 없이 실제 영상 완성까지 진행한다. 직접 소재 입력은 선택 사항이다.
2. 독창성: 소재 이름만 교체한 반복 대본, 사실상 동일한 장면 구성, 타인의 자료를 단순 낭독·재편집하는 방식을 피한다.
3. 가치: 영상마다 전달할 새로운 정보, 설명 관점 또는 오락적 가치가 있어야 한다.
4. 품질: 출처·사실·권리·기술적 완성도를 검증하며 중대한 문제가 있으면 게시하지 않는다.
5. 수익성: 재생성까지 포함한 실제 비용과 제작 시간을 기록하고, 양산보다 품질 대비 비용 효율을 우선한다.
6. 운영: 초기에는 사람 검수 및 게시 승인 필수. 비공개 업로드와 공개 전환은 별도 승인한다.

## 3. 제작 및 검수 파이프라인

| 단계 | 책임 | 필수 결과 |
|---|---|---|
| DISCOVER/SELECT | 소재 기획 | 채널 기반 후보 5~10개, 기존 콘텐츠 비교, 선정 이유, 차별점, 검수 필요 여부와 조사할 주장 |
| RESEARCH | 자료 조사 | 실제 검색·확인된 출처, 주장-근거 연결, 가상·추정·사실 구분 |
| SCRIPT | 작가 | 영어 대본, 소재에 맞는 Hook·전개·결말, 시청자에게 전달하는 가치 |
| SCRIPT_REVIEW | 비평 | 사실 오류, 반복성, 과장, 출처 누락, 설명 가치 검토 및 수정 지시 |
| SCENE_PLAN | 영상 감독 | 장면별 내레이션, 시각화 의도, 프롬프트, 길이, 자막 계획 |
| MEDIA/RENDER | 제작·편집 | 이미지, TTS, 자막, FFmpeg, 권리 확인된 음원, 실제 MP4 |
| METADATA | 게시 정보 | 제목·설명·태그·썸네일 산출물, 출처·합성 표시 검토 |
| QC | 최종 검수 | 기술 검사, 독창성 및 가치 평가, 수정/보류 사유, manifest |
| HUMAN_REVIEW | 운영자 | 실제 영상 재생, 출처·권리·정책 확인, 승인 또는 수정 |
| PUBLISH | 게시 | 승인된 파일의 비공개 업로드, 원격 ID 확인, 공개 별도 승인 |

위 명칭은 논리적 단계이며 DB enum이나 API 이름을 지금 확정하는 것은 아니다. 한 LLM에 역할별 프롬프트를 적용해도 된다. 작가와 비평가의 평가 입력·결과는 구분하되 별도 AI 업체나 프로세스를 강제하지 않는다. 비평 AI의 판단은 사실·권리·정책 적합성을 보증하지 않는다.

## 4. 소재와 대본 독창성

### V2-02: 소재 발굴

- 기존 Topic 정규화 키와 제목 중복 방어를 재사용한다.
- 최근 및 관련 콘텐츠의 제목, 핵심 질문, 요약, 설명 관점과 후보를 비교한다. 핵심 질문과 설명 관점이 같거나 제목과 표현만 바꾼 소재는 차단한다.
- 일부 유사해도 독립적인 콘텐츠 가치가 있으면 근거를 남기고 독창성 점수를 감점한다. 같은 분야에서 새로운 질문과 설명 관점이 확인되면 차별화 이유를 기록하고 허용한다.
- 중복 여부가 불확실하면 비교 근거와 검수 필요 여부를 저장한다. 불확실 후보는 자동 선정하지 않으며, 사람 검수로 차별성이 확인되면 선정할 수 있다. 불확실 후보만 남은 경우의 검수 대기는 후속 구현 범위다.
- 기존 제품 기획의 소재 점수(채널 적합성 20, 흥미/Hook 25, 차별성 20, 시각화 15, 근거 확보 15, 비용 5)를 유지한다. 품질 평가 점수와 혼용하지 않는다.
- 후보별 핵심 질문, 예상 가치, 유사 콘텐츠 참조, 선정/제외 이유를 보존한다.
- 초기에는 기존 DB 조회와 간단한 텍스트 비교, 필요 시 LLM 비교로 충분하다. 벡터 DB나 대규모 크롤러는 후속 필요에 따라 검토한다.
- 현재 V2-02는 적격 후보가 없으면 근거를 저장하고 실패 처리하며 재발굴하지 않는다. 후속 재발굴 조건은 §6을 따른다.

### DISCOVER/SELECT에서 RESEARCH로 전달하는 정보

- 과학적 질문, 가설, 가상 시나리오와 그 전제, 미검증 주장을 구분해 기록한다. 검증이 필요한 주장은 확정 사실로 채택하지 않고 조사 질문, 확인할 근거와 함께 RESEARCH로 전달할 수 있다.
- 허위 출처, 이미 확인된 사실 오류, 검증되지 않은 내용을 사실로 단정하는 표현은 소재 단계에서도 허용하지 않는다.

### V2-03: 조사 및 대본

- 실제로 조회한 출처의 URL·제목·발행 주체·확인 시점과 주장별 근거를 기록한다. RESEARCH는 전달받은 미검증 주장을 검증하고, SCRIPT는 실제 근거와 대본의 각 사실 주장이 일치하는지 확인한다. 허위 URL·인용·수치는 허용하지 않는다.
- 과학적 가상 시나리오의 전제, 알려진 사실, 추론, 불확실성을 구분한다.
- 외부 자료 문장을 그대로 읽는 방식이 아니라 독자적인 설명과 시각적 해석을 작성한다. 필요한 인용은 권리와 인용 조건을 검토한다.
- 최근 대본의 Hook, 핵심 주장, 전개 구조, 결말과 비교한다. 채널 브랜딩이나 공통 자막 스타일만 동일하다는 이유로 차단하지 않는다.
- 검수 단계는 구체적 문제 위치, 근거 및 개선 방향을 반환한다. 근거 부족 또는 중요 사실 오류가 해소되지 않으면 제작/게시 진행을 막는다.

## 5. 영상 제작 품질

### V2-04: 장면 및 편집

초기 단일 9:16 렌더링 템플릿을 유지하되, 소재별로 장면 수·길이·이미지·카메라 이동·설명 순서가 달라질 수 있도록 한다. 동일한 엔진 사용과 동일한 콘텐츠의 반복 생산을 구분한다. 과학 설명에 적합하면 도식, 비교, 규모 표현, 시간 흐름 등을 활용한다. 이미지의 시각적 인상보다 설명과의 관계를 우선한다.

초기 AI 동영상 생성은 후속 범위로 유지한다. 이미지·TTS·자막·FFmpeg와 권리 확인된 자산으로 먼저 품질을 검증한다. 유료 Provider, 가격, 상업적 이용 조건은 실제 연결 전 검증하고 승인한다. 무료 로컬 모델도 라이선스 확인 대상이다.

### V2-05: 기술 검사 및 품질 평가

첫 IFNOVA 영어 Shorts는 40~60초, 1080×1920, 실제 재생 가능한 MP4가 기준이다. FFprobe 및 로컬 검사로 파일 무결성, 해상도, 길이, 오디오 스트림, 자막 타이밍과 검은 화면·누락 등 주요 문제를 확인한다. 자동 검사만으로 모든 음성·시각 오류를 검출할 수 없으므로 사람 검수를 유지한다.

| 평가 항목 | 배점 | 확인 기준 |
|---|---:|---|
| 독창성 | 25 | 기존 영상과 구별되는 질문·설명·구성 |
| 정보 정확성 | 20 | 실제 근거, 전제 및 불확실성 표시 |
| 교육적·오락적 가치 | 20 | 시청 후 얻는 정보 또는 경험 |
| 스토리텔링 | 15 | 자연스러운 Hook·전개·결말 |
| 시각적 완성도 | 10 | 장면 적합성, 음성·자막·영상 동기 |
| 시청 몰입도 | 10 | 속도, 이해도, 불필요한 반복 여부 |
| 합계 | 100 | 내부 운영 지표 |

| 점수 | 처리 |
|---|---|
| 75~100 | 제작 완료 및 사용자 검수 대상 |
| 60~74 | 문제가 있는 부분만 개선한 뒤 재평가 |
| 0~59 | 재기획 또는 폐기 |

85점 이상은 우수 품질 목표다. 위 점수 구간은 내부 운영 정책이다. YouTube 공식 수익 창출 심사는 별도 기준을 따른다.

저작권 침해·권리 미확인, 허위 출처, 심각한 사실 오류, 기술적 결함, 정책 위반, 실질적으로 반복된 콘텐츠는 점수와 무관하게 게시를 차단한다. 필요한 합성 표시 미확인, 해결되지 않은 정책 적합성 문제, 산출물 해시 불일치도 기존 차단 조건을 유지한다.

검수 결과에는 항목별 점수, 판단 근거, 문제 위치, 수정 제안, 차단 사유, 평가 모델/프롬프트 버전 및 평가 대상 산출물 식별자를 기록한다. 주관적인 점수만으로 승인 또는 공개하지 않는다.

## 6. 제한된 개선과 비용 보호

- 실패한 단계나 장면만 다시 생성하고 변경으로 무효화되는 후속 결과만 재계산한다.
- 최종 품질 개선은 최초 생성 후 최대 2회다. 가능한 경우 문제가 있는 장면, 대본, 이미지 또는 음성만 개선한다. V2-01의 기술 오류 재시도와 별개로 계산한다.
- 모든 소재가 부적합하면 향후 같은 제작 요청의 남은 예산 내에서 최대 1회 재발굴을 허용하는 방향으로 설계한다. 현재 V2-02의 재발굴 금지를 유지하며, 구현은 별도 배정에서 검토한다.
- 제작 요청 ID에 소재 발굴·검수·재생성 비용까지 합산한다. 기존 시스템/채널/영상 한도와 지출 차단 스위치를 우회하지 않는다.
- 재생성 전 예상 비용과 잔여 한도를 확인한다. 외부 호출 결과 불명은 기존 복구 절차로 처리하며 재발굴이나 재생성으로 우회하지 않는다.
- 예산 부족 또는 개선 한도 소진 시 검수 대기/실패/폐기 중 적절한 상태로 전환하며 결과와 비용 이력을 보존한다.
- 수정 후 필요한 품질 검사를 재실행한다. 승인된 revision/run/manifest 또는 파일이 변경되면 이전 승인은 무효화한다.

## 7. 게시와 수익화 정책

AI 사용 자체를 금지하거나 AI 탐지 회피를 목표로 하지 않는다. 반복적·대량 생산된 저가치 콘텐츠와 재사용 콘텐츠에 관한 YouTube 수익화 정책을 고려한다. 독창적 콘텐츠라도 채널 전체 심사, 자격, 저작권, 광고 적합성 등에 따라 수익화가 제한될 수 있다.

- 현실적으로 보이는 의미 있는 합성/변경 콘텐츠 등 공식 정책상 공개 대상 여부를 검토하고 필요한 경우 정확히 표시한다. 모든 AI 사용을 일률적으로 공개 대상으로 취급하지 않는다.
- 자산별 출처 및 라이선스, 필요 시 구매/사용 증빙과 상업적 이용 조건을 보존한다. 자동 도구의 결과는 법적 권리 확정이 아니다.
- 사람 검수 화면에서 실제 영상, 제목·설명, 출처, 권리, 합성 표시, 품질 및 비용을 확인한다.
- 승인된 revision/run/manifest와 파일 SHA-256을 검증한 후 별도 승인된 비공개 업로드만 진행한다. 공개 전환은 별도 승인한다. 결과 불명 시 중복 업로드를 차단한다.
- 실제 연동 및 정책 게이트 구현 시 공식 최신 문서를 다시 확인하고 확인 일자 및 적용 범위를 기록한다. 아래 링크는 참고 경로이며 이번 문서 작성에서 최신 정책을 독립 재검증하지 않았다.

## 8. 최소 저장 및 UI 요구사항

기존 Topic/Content/Revision/Run 및 v2 제작 요청, 산출물 manifest를 우선 활용한다. 후보 평가, 주장-출처, 검수 결과, 차단 사유, 권리 메타데이터를 기존 JSON/산출물/테이블 구조에 맞춰 저장할 수 있는지 먼저 검토한다. 새로운 테이블은 조회·정합성·복구에 필요한 경우만 추가하며 이번 문서로 물리 스키마를 확정하지 않는다.

기존 제작/검수 화면에 선정 이유, 유사 콘텐츠 경고, 출처, 품질 점수와 구체적 문제, 비용 및 잔여 개선 횟수, 미리보기, 부분 수정, 승인 가능 여부를 표시한다. 별도 관리자 품질 대시보드나 워크플로우 편집기는 최초 범위에서 제외한다.

## 9. 로드맵 반영 및 인수 시험

| 단계 | 추가 인수 조건 |
|---|---|
| V2-01 | 품질 요구로 별도 엔진을 만들지 않는다. 향후 검수/재생성 호출도 동일 제작 요청 비용과 복구 계약을 사용할 수 있어야 한다. |
| V2-02 | 기존 결합 수정 후 종료 전 최소 변경으로 실질 중복 차단, 독립 가치가 있는 일부 유사 소재 감점, 새 질문·관점 허용, 불확실 후보의 자동 선정 제외, 차단·감점·검수 필요 UI 표시를 검증한다. 재발굴 금지는 유지한다. |
| V2-03 | 실제 주장-출처 연결, 가상과 사실 구분, 대본 비교, 허위 출처/근거 부족 시 차단, 검수 지적 수정. |
| V2-04 | 공통 렌더러를 쓰되 서로 다른 소재에 적합한 장면 구성. 자산 권리 기록과 부분 재생성 경로. |
| V2-05 | 실제 MP4 및 품질 보고서·manifest 완성. 기술 실패/중대한 사실 오류/권리 미확인 차단, 개선 비용·횟수 제한, 수정 시 승인 무효화. |
| V2-06 | 승인 파일만 비공개 업로드, 정책/합성 표시 확인, 불명 결과 중복 방지, 공개 별도 승인. |
| V2-07 | 반복 운영에서도 중복 콘텐츠 비교, 제작량보다 품질 우선. 자동 공개 옵션은 별도 설계·승인. |
| V2-08 | 조회수, 시청 지속률, 비용, 수익(권한 허용 시)을 비교하고 충분한 표본과 사람 검토를 통해 전략 개선. |

MVP1은 사용자 소재 입력 없이 실제 IFNOVA MP4·출처·비용·게시 정보·manifest·품질 보고서를 생성하고 사람이 검수할 수 있는 상태다. FAKE만으로 통과하지 않는다. 테스트용 샘플 2개 이상으로 중복/차별화 판정과 품질 차단을 확인하되 여러 편의 유료 영상 제작을 강제하지 않는다. MVP2는 승인된 비공개 업로드 및 원격 ID 확인이며 수익화 성공을 뜻하지 않는다.

초기 운영 실험은 IFNOVA 영어 Shorts 40~60초 영상 30개를 대상으로 한다. 하루 1~2개 제작, 영상당 2,000원 이내를 목표로 하며 게시 전 사용자 검수를 거친다. 실제 시청 지속률, 조회수, 시청자 반응과 수익을 바탕으로 정책을 조정한다. 제작량은 품질·수익화의 보장을 뜻하지 않는다. 비용 목표는 기존 DB 한도와 별개인 실험 지표다.

## 10. 구현 인수인계

승인된 최신 v2 문서와 본 품질 요구사항을 읽고 V2-02~06 배정 단계에서 구현 및 자체 테스트한다. V2-01의 최소 실행기에는 향후 품질 검수 및 부분 재생성을 지원하는 공통 실행/비용 경계만 고려한다. 별도 범용 AI 에이전트 프레임워크, 벡터 DB, 품질 관리 시스템을 선행 개발하지 않는다. 공통 DB/API 변경은 Codex와 조율한다. 비용·게시 안전성 독립 리뷰를 유지한다.

이번 개정은 문서 정책에 한정한다. Claude 결합 수정 완료 후 V2-02 종료 전 최소 변경으로 소재의 차단·감점·검수 필요 분류와 근거 표시를 별도 배정한다. DISCOVER와 SELECT 재검사에 같은 자동 선정 조건을 적용하고 기존 결합 테스트와 함께 검증한다. 미검증 주장 인계는 V2-03, 최종 품질 점수와 부분 개선은 V2-05에서 구현한다.

## 11. 변경 기록 및 가정

- 사용자 동의: 독창성·품질·수익성 중심의 자동 제작 및 정책 준수 요구사항 추가.
- 정책 개정: 소재 중복 판정·검수 처리, 소재 단계와 조사 단계의 사실 검증 책임, 최종 품질 점수 구간, 최대 개선 횟수와 초기 운영 실험 목표를 확정했다. 운영 데이터로 후속 보정한다.
- 미검증: 최신 원격 소스 및 정책, 실제 DB 설정, Provider 단가·라이선스. 실제 연동 전에 다시 검증한다.
