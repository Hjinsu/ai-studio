## 실행 순서와 채택

1. 요청 ID·채널/실행 모드·비용 한도/정책을 소재 조사 전에 동결한다. DISCOVER 후보를 파일로 교환하며 서버가 구조·근거·중복을 평가한다. 기존 SELECT 잠금·최신 후보 재검사·선정 지문을 통과한 결과로 RESEARCH/SCRIPT/SCENES를 연결한다.
2. `v2-media-2`에서 SCENES → TTS → IMAGE 순서로 실행한다. TTS PCM의 실측 길이와 검증된 장면 경계로 최종 미디어 계획을 만들고, 예산을 검증한 후에만 이미지·클립을 발송한다. 기존 `v2-media-1` 순서와 데이터는 유지한다. 자막 OFF 단계는 환경에 맞는 명시적 검증 결과로 처리하고, 현재 enum과 과거 데이터 호환은 공통 구현 계획을 따른다.
3. RENDER 준비에서 이미지/클립/절차 애니메이션과 오디오 큐를 확정한다. 화면 사건의 PTS를 trim·전환을 반영한 출력 좌표로 매핑한다. 핵심 동작의 후보가 불확실하면 사용자 큐 조정 또는 검수 대기, 부수 큐는 생략·ambience·무음으로 대체한다. 클립 및 타임라인 변경은 관련 큐와 인수 해시를 무효화한다.
4. 보호된 FFmpeg로 화면과 오디오를 합성하고 기술 QC·사용자 콘텐츠 인수를 거친다. 대본 재미와 완성 영상의 연출 재미를 따로 평가한다. 원본/확정 자산, plan, 권리, 비용, QC와 revision/MP4 해시로 재현 및 인수를 지원한다.

## 오디오와 로컬 라이브러리

Claude가 BGM 분위기·전환·침묵 및 동작별 `soundEvents`를 제안하고 Codex가 과학 맥락, 낭독 명료도, 개그 타이밍을 검수한다. 앱이 narration/BGM/Foley/SFX/ambience와 코미디·전환 효과의 실제 자산, 레이어 gain과 배치를 결정한다. 사용자 검수 화면은 실제 프리뷰와 큐 위치·근거를 보여 주고 선택 또는 수정된 위치를 기록한다. AI가 추정한 시각을 실제 클립의 동작으로 채택하지 않는다.

기존 카탈로그와 권리 표현을 활용해 음원 등록·분류, 분위기/태그 검색, 길이·고유 ID·SHA-256, 라이선스·출처 URL·증빙·상업 이용과 편집/게시 조건·저작자 표시를 관리한다. 확인되지 않은 음원은 사용하지 않는다. 채널별 이력은 확정 manifest로 추적한다. 음악 생성을 편당 API 호출에 포함하지 않는다. 오디오의 Ducking, Fade In/Out, Crossfade, 겹침 제어, 정규화, 피크 방지와 생성 영상 원본 오디오 제외는 기존 오디오 계획을 적용한다. 진공 등 과학적으로 부적절한 환경음은 연출 효과로만 사용한다. - **유료 운영 차단**은 실제 청구 대조, SKU별 최대 청구/환율·권리 근거, 보호된 혼합 렌더와 B01/B02·불명 복구 검증, 최초 영상의 사용자 인수 및 별도 운영 승인 미충족이다. Worker의 자동 검색·무인 반복은 이용 조건과 계정 사용 범위 확인 전 비활성화한다. 사용자 실행형 파일 교환을 지원하며 추가 크레딧·유료 API 자동 전환을 금지한다.
- **후속 개선**은 동작 검출 정밀도와 음원 태그/채널 이력 개선, 음원 카탈로그 관리 고도화, V2-07 예약·자동화, V2-06 번역·더빙, 비활성 공급자 재평가다. 고정 마스코트·복수 화자·Blender는 BACKLOG다. 별도 추가 스파이크를 배정하지 않는다.
