# AI Studio v2 — 제품 기획서

버전 2.0 / 2026-11-26 KST / 사용자 승인

## 목적
본인 한 명이 개인 PC에서 여러 YouTube 채널을 운영하여 콘텐츠 수익을 창출한다. SaaS 판매, 외부 고객, 기업용 운영 기능은 범위 밖이다. 성공은 코드량이나 테스트 수가 아니라 실제 영상 품질, 제작 시간, 비용, 운영 개입 횟수 및 수익으로 판단한다. 수익은 보장되지 않는다.

## 첫 제품 완료 기준
IFNOVA 한국어 Shorts 40~60초, 1080×1920, 9:16. 사용자는 채널 방향과 예산만 설정하고 제작 시작을 누른다. **소재를 직접 입력하지 않아도** 후보 발굴, 평가, 선정, 조사, 대본, 장면, 이미지, TTS, 자막, 합성, 게시 정보, 자동 품질 검사까지 자동 진행한다. 사람이 재생할 수 있는 실제 MP4 및 출처·비용·산출물 manifest가 완성되면 MVP1 통과. 테스트 대역 MP4는 기술 검증이지 제품 완료가 아니다. MVP2는 승인된 실제 파일의 비공개 업로드와 원격 ID 확인, 공개는 별도 승인. MVP3는 예약 반복 제작 및 다채널 운영, MVP4는 Longform·성과 최적화. 최종적으로 채널별 자동 게시 옵션을 제공하되 초기에는 사람 승인 필수.

MVP1에는 독창성·사실성·출처·권리·기술 검수 결과와 사람이 검토할 품질 보고서를 포함한다. 중대한 문제는 진행을 보류하고 개선 시에도 같은 제작 요청 한도를 적용한다. [품질·수익화 요구사항](05_CONTENT_QUALITY_AND_MONETIZATION.md)

## 기능 명세
| 기능 | 최초 구현 | 후속 확장 |
|---|---|---|
| 채널 | 기존 채널 관리, 언어·주제·금지 주제·스타일·예산·길이·프롬프트 | 채널별 템플릿, 예약, 복수 채널 동시 운영 |
| 소재 | AI 후보 5~10개(설정값), 과거 제목/정규화 키/유사성 검사, 평가 후 자동 선정, 직접 입력은 선택 | 실시간 트렌드, 경쟁 채널 분석, 성과 기반 추천 |
| 조사 | 실제 검색 결과 및 출처 수집, 주장별 근거, 추정/가상과 사실 구분, 근거 부족 시 다른 후보 또는 검수 대기 | 출처 신뢰도 고도화 |
| 대본 | 채널 제작 언어의 구조화된 Hook·전개·결말, 길이 검증, 출처 연결 | 여러 스타일, 장문, A/B 분석 |
| 장면 | 순서·내레이션·시각 프롬프트·예상 길이, 제한된 장면 수 | 고급 연출 및 AI 동영상 |
| 미디어 | 이미지, TTS, 타이밍 기반 자막, 권리 확인된 배경음 선택 | 영상 생성, 다양한 모델 |
| 렌더링 | FFmpeg 고정 템플릿, 이미지 이동/확대, 전환, 음성 및 자막, FFprobe 검사 | 템플릿 편집기 |
| 게시 정보 | 제목·설명·태그·출처·합성 표시 필요 여부, 썸네일 산출물 | 플랫폼별 최적화; Shorts 썸네일 설정은 실제 API 지원 범위 확인 |
| 검수 | 재생, 출처/권리/사실성 확인, 단계 또는 장면 재생성, 승인 무효화 | 자동 품질 평가 및 제한된 개선 루프 |
| 게시 | OAuth, 승인 파일 비공개 업로드, 원격 ID 확인 | 예약/채널별 자동 게시, 별도 정책 승인 |
| 성과 | 제작 시간·비용·실패 횟수 기록 | 조회수·시청 지속률·수익(권한 허용 시), 소재/템플릿 비교 |

소재 후보는 5~10개, 평가는 채널 적합성 20, 흥미/Hook 25, 차별성 20, 시각화 가능성 15, 근거 확보 15, 비용 5로 총 100점이다. 동일 질문·동일 관점과 단순 제목·표현 변경은 차단한다. 일부 유사해도 독립적인 가치가 있으면 독창성 점수를 감점하고, 새 질문과 관점은 허용한다. 중복이 불확실하면 검수 필요를 기록하고 자동 선정 대상에서 제외한다. 화면에서 차단·감점·검수 필요와 각각의 근거를 표시한다.

소재 단계는 과학적 질문·가설·가상 시나리오·미검증 주장을 구분한다. 미검증 주장은 검증 과제로 넘길 수 있으며, 허위 출처와 확인된 사실 오류는 차단한다. RESEARCH와 SCRIPT는 실제 출처와 주장별 근거를 검증한다. 현재 V2-02는 적격 후보가 없을 때 실패하며 재발굴을 수행하지 않는다.

최종 품질은 기존 6개 항목과 총 100점을 유지한다. 75점 이상은 제작 완료 후 사용자 검수, 60~74점은 문제가 있는 부분만 최대 2회 개선, 59점 이하는 재기획 또는 폐기다. 85점은 우수 품질 목표다. 저작권·사실·기술·정책·실질 반복에 따른 게시 차단은 점수와 별개로 적용한다.

## 사용자 화면
기존 로그인/채널/예산 UI 활용. 제작 화면 하나에서 자동 제작 시작, 후보/선정 이유, 단계별 진행, 비용, 오류, 취소/재개, 파일 미리보기 및 부분 재생성 제공. 검수 화면에서 제목·설명·권리·출처·합성 표시·승인 확인. 게시 이력 화면에서 원격 ID와 상태 확인. 상세 대시보드와 자동 분석은 후속.

## 초기 설정 제안
IFNOVA: 과학적 근거를 바탕으로 가상 시나리오를 설명하는 한국어 사건 중심 과학 코미디. 기존 설정을 우선 조회하되 사용자 DB를 임의 변경하지 않는다. Shorts 2,000원, Longform 10,000원, 일 20,000원, 월 300,000원은 기존 계획값이며 실제 DB/가격 검증 전 확정하지 않는다. V2-04는 이미지 중심 기술 인수다. V2-05는 AI 클립과 절차적 애니메이션을 검토한다. 공급자/모델은 실제 가격, 권리, API, 응답 복구 가능성 검증 후 선택한다.

초기 운영 실험은 IFNOVA 한국어 Shorts 40~60초 영상 30개를 대상으로 한다. 하루 1~2개, 영상당 3,000원 이내를 권장 목표로 삼고 게시 전에 사용자 검수를 거친다. 실제 시청 지속률, 조회수, 시청자 반응과 수익으로 평가 규칙을 보정한다. 이 수치는 운영 실험 목표이며 지출 설정이나 성과 보장을 뜻하지 않는다.

## 제외 원칙
기업용 RBAC 확장, 다중 서버, Kafka/Redis/Kubernetes, 범용 워크플로우 플랫폼, 대규모 부하 시험은 최초 범위 제외. 자동 소재 발굴과 조사 등 제품 핵심 기능은 제외하지 않는다. YouTube 정책·수익화 자격·AI 표시·저작권은 연동 직전 공식 문서 확인, 반복적 저가치 콘텐츠 대량 생산을 목표로 삼지 않는다.

공급자 선택·제작 원가 및 자동 소재 발굴의 후속 제안은 [공급자·원가](06_AI_PROVIDER_AND_PRICING.md)와 [소재 발굴·데이터 API](07_TOPIC_DISCOVERY_AND_API.md)를 참조한다.
