V2-01의 완료를 위해 미래 기능 전체에 대한 범용 엔진을 구현하지 않는다. 다만 실제 유료 작업은 해당 작업의 비용·중복·복구 게이트 통과와 사용자 승인 이후만 허용. V2-02~04의 무효과 구현은 안전 계약 범위 내 병렬 가능. 실제 Provider를 조기 연동해도 최종 제품 검증은 V2-05에서 수행한다.

단계별 품질·수익화 인수 기준은 [05 요구사항](05_CONTENT_QUALITY_AND_MONETIZATION.md)을 따른다.

## MVP1 인수 시험
- 채널 선택 후 소재 미입력 상태로 자동 제작 시작.
- 자동 소재 선정 근거와 출처 검증, 중복 후보 제외, 자료 부족 시 정지.
- 실제 LLM/이미지/TTS 또는 권리 확인된 로컬 대체를 사용해 재생 가능한 1080×1920 영어 MP4(40~60초) 완성. 가짜 대본/미디어로 완료 판정 금지.
- 음성·자막·장면 동기화, 검은 화면/누락 등 기술 검사와 사람 검수.
- 제작 비용 기록, 예산 초과 시 차단, 재시작·오류·부분 재생성으로 불필요한 유료 호출이 반복되지 않음.
- 제목·설명·출처·권리·합성 표시 검토 정보, manifest 및 품질 보고서 생성. 샘플 2개 이상으로 중복·차별화 및 품질 차단 검증.

## MVP2 인수 시험
- 사용자가 승인한 동일 revision/run/manifest/hash만 업로드.
- 비공개 업로드 별도 승인 및 실제 원격 ID 확인. 타임아웃 후 동일 파일 재업로드 방지.
- 공개 전환 별도 승인. 비공개 업로드만으로 수익화 또는 공개 운영 성공 주장 금지.

## 작업 단위 보고 양식
작업 ID / 기준 및 결과 SHA / 변경 파일과 DB 계약 / 완료한 사용자 흐름 / 실행한 테스트와 결과 / 미실행 검증 / 남은 위험과 다음 작업. 차단 문제는 즉시 보고. 단순 구현에 별도 설계 보고서 남발 금지.
