## 착수 범위

**S0 무과금 준비부터 착수 가능.** 설계 SHA를 기준으로 스파이크 작업 브랜치와 별도 worktree를 사용하고 시작 시 Git 기준선과 작업 범위를 기록한다. S1~S4는 호출 목록과 계정별 최대 청구액을 사용자에게 제출해 별도 승인을 받은 뒤 진행한다. 무료 크레딧·체험판을 활용한 생성도 승인 전에는 실행하지 않는다. 공통 계약 및 제품 구현은 스파이크 결과와 최종 설계 승인 이후 착수한다.

## S0 준비 절차

1. [공급자별 공식 문서 링크](V2-05_PROVIDER_SPIKE.md)를 기준으로 실제 제출에 사용할 API·SKU·모델 ID를 확인한다. 확인 시각(UTC), 출처, 계정/리전 가용성, 허용 입력과 출력, 권리, 최소 청구 단위, 실패·취소 과금 및 job 조회·취소·결과 복구 조건을 기록한다. 확인하지 못한 항목은 UNKNOWN 또는 NOT_VERIFIED로 표기한다.
2. 아래 호출별로 요청의 의도와 파라미터, 청구 가능 최대 토큰·문자·이미지·초, 원통화 최대액, 승인 환율 가정, 세금·수수료, 최대 원화액을 적는다. 크레딧이나 무료량을 차감하기 전 요금으로 산정한다. 키를 발급하거나 결제 수단을 연결하지 않아도 공개 계약 검증과 로컬 준비를 진행할 수 있다.
3. 로컬 표본을 준비한다. 사실 근거가 고정된 한국어 대본 소재 2개, 전문 용어·숫자·단위·약어가 포함된 TTS 표본 2개와 비교 cue, 공통 스타일이 적용된 세로 이미지 프롬프트 3개, 행성 회전과 낙하 상황 개그용 시작 이미지·동작 프롬프트를 준비한다. S4에서 같은 동작은 동일 시작 이미지 해시를 재사용한다. 평가표와 호출 원장은 빈 양식으로 준비한다.
4. S0 결과로 호출별 최대액과 합계, SKU별 실행 가능 여부, 계정에서 사용자 조치가 필요한 항목, 미확인 계약을 보고한다. 보수적 최대액이 입증되지 않은 호출은 승인 요청 목록에서 보류로 표시한다. 계정·가격 확인 중에는 생성·테스트 요청을 전송하지 않는다.

## API 키와 계정 준비

환경변수 이름은 실행기에서 사용할 제안이다. 운영자는 발급 및 결제 준비의 승인 범위를 확인한 뒤 키를 로컬 비밀 저장소에 보관하고 실행 프로세스에만 주입한다. 계정 조회에는 기존 승인 접근을 사용한다. 결제 연결·충전·구독과 실제 호출 지출은 각각 필요한 사용자 승인 범위를 확인한다. 자격증명 파일·키·토큰·서명 URL·결제 개인정보는 Git, 채팅, 산출물과 로그에서 제외한다. ElevenLabs는 비교 후보이며 기본 호출 목록에는 포함하지 않는다.

## 실패 및 중단 조건

- 호출 전에는 모델·리전·권리·청구 단위, 파라미터의 청구 상한, 계정 접근, 승인 잔액을 재확인한다. 근거 부족 또는 한도 초과 시 발송을 보류한다.
- 실패·타임아웃·취소·job ID 유실·초과 청구·권리 또는 규격 불일치가 발생하면 해당 실험의 후속 유료 호출을 중단한다. SDK·HTTP 쓰기 자동 재시도를 끈다. 자동 재제출·대체 SKU 발송·재생성은 금지한다.
- 이미 발송된 작업은 확보한 ID로 조회하고 청구 증거를 확인한다. ID 또는 비용이 확인되지 않으면 UNKNOWN과 최대 비용 노출을 기록한다. 실제 초과 청구는 실비와 근거를 보존하고 사용자에게 보고한다.

## 산출물 저장과 전달

- 저장소 밖의 사용자 승인 로컬 작업 폴더에 `S0/`부터 `S4/`까지 구분한다. 텍스트·평가표는 UTF-8, 구조화 기록은 JSON/JSONL, 자산은 원본 확장자를 사용한다. 원본 입력·출력의 SHA-256, 크기, 포맷, 생성 시각 UTC를 manifest에 기록한다. S4는 길이·해상도·FPS도 보존한다.
- 산출물은 `sources.md`(공식 계약·권리·검증일), `call-plan.json`(실험 ID·표본 ID·모델·파라미터·호출 한도·최대 통화 금액/원화액·승인 상태), `calls.jsonl`(시각·결과·job ID·실제 청구/증빙·불명 상태), `manifest.json`(상대 경로·해시), `evaluation.md`(표본별 근거와 사람 평가), `report.md`(결과·차단·다음 승인)로 제안한다. S0에서는 호출 계획과 표본만 기록하고 실행 결과는 미실행으로 표시한다.
- 생성 미디어, 민감 응답 및 원본 청구 증빙은 Git 밖에 보관한다. 커밋 가능한 보고서에는 집계 비용, 검증 결과, 비밀정보를 제거한 증거 참조만 남긴다. 자동 평가 점수는 사람의 판단 근거로 첨부한다.
