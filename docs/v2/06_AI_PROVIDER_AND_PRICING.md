## 1. 목적 및 범위

AI Studio는 한 명의 운영자가 개인 PC에서 여러 YouTube 채널을 운영하는 로컬 제작 도구다. V2-05 검증 대상은 IFNOVA 한국어 과학 코미디 Shorts(40~60초, 1080×1920)다. 기존 영어·이미지 중심 원가 예시는 비교 기준으로 남기고 한국어 TTS 및 동영상 사용 시나리오는 연동 전 재산정한다. 영상당 2,000원, 일 20,000원, 월 300,000원은 기존 계획의 비교 예시다. IFNOVA V2-05의 확정 편당 상한은 3,000원이며 [공급자 재검증 및 원가](V2-05_PROVIDER_SPIKE.md)를 적용한다. 실제 한도는 활성 정책 및 사용자 승인으로 확인한다. Longform은 480~720초, 10,000원 기존 목표 한도를 검토한다.

현재 V2-03은 FAKE/FIXTURE 및 저장·비용·복구 계약 검증 단계다. V2-04에서 로컬 미디어 및 MP4 제작을 검증하고 V2-05에서만 승인된 실제 공급자와 의미 검수를 연결한다. 이 문서는 가격·후보·선정 기준을 정리한 것으로 기존 개발 범위, DB, 파이프라인을 변경하거나 유료 호출을 허가하지 않는다.

## 4. Shorts 원가 모델

아래 수량·길이·비율·비용 배분은 비교 가정이다. IFNOVA V2-05 운영 계획은 소재별 SCENES 후보와 서버 가격 검증으로 선택한다. [동적 연출 설계](V2-05_IMPLEMENTATION_PLAN.md)

### 4.1 사용량 가정 (실측 아님)

| 단계 | 입력 토큰 | 출력 토큰(추론 포함) |
|---|---:|---:|
| DISCOVER | 5,000 | 2,000 |
| RESEARCH | 12,000 | 3,000 |
| SCRIPT | 8,000 | 2,000 |
| SCENES | 6,000 | 3,000 |
| METADATA | 3,000 | 1,000 |
| QC | 10,000 | 3,000 |
| 합계 | 44,000 | 14,000 |

- 텍스트: $0.032 = 43.008원.
- 검색: 4쿼리 × $0.014 = 75.264원 (비교 산정용; Grounding 이용 승인 아님). Brave 공개 기본단가 적용 시 26.88원이나 저장권 포함 요금 미확정.
- 음성: 800자 × $16/100만 = 17.2032원.
- 이미지 부가 입력·출력 및 추가 검수 여유: 10원 가정. 실제 계량값이 아님.
- 이미지 외 합계: 145.4752원. 별도 독립 의미 검수 호출, 추가 원문 조회 유료 요금, 결제 수수료 및 실패 재작업은 여유 비용으로 검증해야 한다.

### 4.2 이미지 구성별 비교

| 시나리오 | 이미지 구성 | 세전 원가(원) | 세금 10% 가정(원) |
|---|---|---:|---:|
| 절약 | Lite 12장 | 687 | 756 |
| 혼합 추천 | Lite 8장 + 일반 4장 | 867 | 954 |
| 일반 | 일반 1K 12장 | 1,226 | 1,349 |
| 일반 + 재생성 | 일반 1K 14장 | 1,406 | 1,547 |
| 고화질 | 일반 2K 12장 | 1,774 | 1,952 |
| 고화질 + 재생성 | 일반 2K 14장 | 2,046 | 2,250 |

Lite 8장 + 일반 4장은 이미지 품질과 비용을 비교하는 예시다. 정상 제작 목표는 1,200~1,700원 이내, 영상당 2,000원은 기존 계획의 예산 기준값이다. 모든 호출 전 예상 최대 비용을 예약하고, 다음 호출이 한도를 넘길 경우 중단한다. 실제 세금 적용 및 운영 예산에 세금 포함 여부는 V2-05에서 일치시킨다.

일 10편은 월 30만원 상한을 초과할 수 있으므로 월 예산 보호가 먼저 작동해야 한다. 초기 운영 실험은 30편, 하루 1~2편, 사람의 공개 전 검수로 제한한다. 수익 및 수익화 승인 보장은 없다.

### 4.4 Longform (V2-08 검증 대상)

10분 영상에 이미지 60장(Lite 48 + 일반 12), 영어 8,000자, 텍스트 입력 200,000/출력 80,000 토큰, 검색 20쿼리($0.014 비교단가), 이미지 부가·검수 100원 가정 시: 이미지 약 3,248원, 텍스트 228원, 음성 172원, 검색 376원, 부가 100원, 합계 약 4,125원(세금 제외). 10% 가정 시 약 4,538원. 실제 긴 영상의 조사·독립 검수·재생성·장면 수가 증가하면 달라진다. 10,000원 목표의 실현 가능성을 검증할 시나리오일 뿐이다. 생성형 동영상, 유료 음악·스톡, PC 전력, 저장공간 및 별도 인프라는 Shorts와 Longform 모두 제외했다.

## 5. 조사 공급자 이용조건 — 활성화 차단 항목

Google Gemini 일반 생성 결과는 Google이 소유권을 주장하지 않지만 유사 결과가 다른 이용자에게 생성될 수 있으며, 사용자의 권리 검토 책임이 남는다(S4). 유료 서비스와 무료 서비스의 데이터 이용 조건이 다르므로 운영 콘텐츠는 승인된 유료 계약을 기본 검토한다.

**Google Search Grounding은 별도로 판단한다.** 공식 약관(S4)은 검색 응답과 링크의 재사용·저장·분석 및 자동 수집에 제한을 두며, 검색 제안 표시 의무도 규정한다. AI Studio의 조사 본문 영속화, 출처 링크 수집, 자동 후속 대본 생성에 그대로 적용할 수 있다고 가정해서는 안 된다. 해당 워크플로우의 허용 여부를 확인하기 전 Grounding을 운영 활성화하지 않는다. 기본 검색 API 역시 계약상 저장권 및 후속 콘텐츠 활용 권한이 확인되어야 한다.

대안: 공개 자료 기관의 허용된 API/원문 직접 조회 및 저장권을 명시적으로 허용하는 검색 공급자. Brave의 공개 기본가격은 저장권 계약 가격과 다를 수 있다(S3). NASA 등 개별 출처의 저작권·제3자 자료·로고 사용 조건, 인용 범위를 확인한다. 문서 조회 성공과 주장 지지 여부는 분리한다. 허위 출처, 지지 부족, 반대 근거를 기존 V2-03 규칙으로 처리한다. SSRF·리디렉션·크기·시간 제한과 외부 문서의 프롬프트 인젝션 방어를 적용한다.

TTS 음성 파일은 Google Cloud 약관과 법률 준수 조건으로 영상에 사용할 수 있다(S5). 음악·음성 모사·이미지의 제3자 권리와 AI 표시 필요성은 별도 검수한다. YouTube 수익화는 독창성·실질 가치·반복 콘텐츠 정책을 충족해야 하며 사실적인 합성물 공개 의무를 점검한다(S6). IFNOVA의 기존 합성 콘텐츠 공개 정책을 유지한다.

## 6. 멀티채널 및 프롬프트 정책

공통 단계 템플릿 + 채널별 분야·전략·언어·시청자·내레이션·시각 스타일·금지 사항 + 현재 확정 소재/이전 단계 결과를 조합한다. IFNOVA/한국어/우주/What If를 실제 엔진에 고정하지 않는다. 채널이 공통 안전 규칙, 비용 상한, 출력 스키마를 우회할 수 없다. 기존 채널 설정과 불변 스냅샷을 최대한 재사용한다.

단계별 공급자/모델/가격 버전/프롬프트 버전/입력 해시/호출 파라미터/출력 스키마 버전을 최초 dispatch 전에 고정한다. 재시작 시 최신 모델 설정으로 재조립하지 않는다. API 키나 민감한 원문을 로그 또는 문서에 저장하지 않는다. 기존 계약에 부족한 설정은 별도 승인 대상으로 기록한다. 신규 범용 프롬프트 엔진이나 테이블을 현재 단계에 도입하지 않는다.

## 7. 가격 및 비용 안전성

- 기존 V2-01 비용 엔진, V2-02 DISCOVER 비용, V2-03 단계 결과 저장을 재사용한다. 새 범용 엔진 금지.
- 예상 최대 원가 = 입력 최대 토큰 × 단가 + 출력/추론 최대 토큰 × 단가 + 검색 최대 쿼리 × 단가 + 이미지/음성 등 사용량 상한. 승인된 환율·세금 정책을 적용하고 실제 비용 단위로 올림한다. 금액은 기존 Decimal/정수 단위 계약에 맞춘다.
- 실제 모델이 사용량 상한을 강제하지 못하는 경우 그 공급자 호출을 승인하지 않는다. 환율·가격의 변경, 만료, 미확인 단가는 신규 발송 전 차단한다.
- 검색·생성·독립 검수·부분 개선 등 별도 과금 호출마다 별도 논리 효과와 영수증을 사용하고 동일 요청 한도에 귀속한다.
- 요청/단계/대상/입력 세대 효과 키, 단일 dispatch 허가, 본문+증거 원자 저장, fenced 적용을 유지한다. 네트워크 호출을 DB 트랜잭션 안에서 수행하지 않는다.
- 결과 불명은 재발송/대체 모델 전환 금지. 미실행 확인 또는 정산·복구 완료 후 별도의 승인된 논리 효과로 재시도한다. 이미 발생한 실패 비용을 누락하지 않는다.
- 실제 가격표/사용량/공급자 영수증과 원장 차이를 대조한다. 무료량이나 캐시 할인은 실측 후 절감으로 반영하며 하드 예산 산정은 보수적으로 유지한다.
- 모델별 rate limit/일일 quota/동시성은 실제 계정과 공식 문서 기준으로 재확인한다. 429는 기존 안전한 실패 및 backoff 계약에 따른다.

## 8. 품질·속도 비교 및 선정 절차 (미실측)

| 대상 | 평가 항목 | 권장 비교 |
|---|---|---|
| 텍스트 | 사실 연결, 독창성, Hook, 길이, JSON 오류, 실제 토큰 | 동일 소재 3~5개, Lite vs 상위 모델 |
| 이미지 | 과학적 개연성, 일관성, 세로 가독성, 디테일, 재생성률 | 동일 프롬프트 Lite vs 일반, 핵심 장면 비교 |
| 음성 | 발음, 자연스러움, 전달력, 목소리 일관성, 실제 길이 | Neural2 vs Chirp 3 HD 또는 Gemini TTS |
| 검색·검수 | 원문 조회, 주장 지지·반대·부족 판정, 누락 주장, 의미 중복 | 사람이 라벨링한 표본 및 권리 검토 |
| 공통 | p50/p95 지연, 오류·타임아웃, 비용, 결과 불명 복구 | 승인된 소량 시험, 모델/가격 버전 기록 |

품질 우선순위: 기존 05 문서의 독창성 25, 정확성 20, 교육/재미 20, 스토리 15, 시각 10, 몰입 10. 최종 75 이상 검수, 60~74 부분 개선, 60 미만 재기획/폐기, 85는 지향값. 필수 차단은 점수보다 우선한다. V2-05 승인 후 최대 2회 부분 개선을 기존 요청 한도 안에서 검증한다. 대본·이미지 모델 품질 우열이나 실제 지연은 아직 측정하지 않았다.

## 11. 인수인계

이 문서는 공급자 후보와 원가 산정 가정을 기록한다. 모델 ID·장면 수·공급자 조합은 비교 사례이며 설정과 실측에 따라 결정한다. 실제 소스코드, DB, 공급자 설정, Migration은 변경하지 않는다. 공급자 결정 및 유료 호출은 별도 사용자 승인 대상이다. 본 문서는 제공된 V2-03 계획과 보고서, 공식 공개 요금 및 약관을 바탕으로 작성했으며 실제 API 호출, 모델 성능 측정, 계정별 과금 검증은 수행하지 않았다.
