## RVX-02-CB: PASS

보강 제품 커밋의 표적 범위에서 이전 인증 세대의 조회·콜백·토스트가 새 세션에 영향을 주는 종료 차단 결함은 확인하지 못했다.

- `runSessionQuery`가 조회 시작 시점의 세대와 실제 Query Promise를 기억하고, 세대 abort 시 아직 같은 Promise인 조회만 취소한다. 새 세대가 같은 키로 만든 조회는 취소하지 않는다.
- `invalidateSessionQueries`는 캐시 작업 전·후와 각 키 처리 중 세대를 확인한다. 세대가 바뀌면 이전 무효화 작업은 `SessionChangedError`로 종료된다.
- `useSessionMutation`은 성공·실패 콜백을 요청 세대에 결합하고, 비동기 콜백이 끝난 뒤에도 세대를 재확인한다. 이전 콜백의 화면 이동·상태 변경은 실행되지 않는다.
- 보호 토스트는 세대의 abort 이벤트로 즉시 제거되며, 같은 세대 토스트의 자동 만료와 인증 흐름 토스트는 유지된다.
- 정산의 원장 확인 조회·성공 처리도 동일한 세대 경계를 사용하고, 기존 예약 ID·본문·멱등 키 보호를 유지한다.
